# روايات البناء — نظام الإدارة الموحّد

نظام إدارة داخلي تفاعلي لمؤسسة **روايات البناء** العقارية، مبني بالكامل بـ HTML/CSS/JavaScript (دون خادم)، يعمل من المتصفح مباشرة أو عبر GitHub Pages، وقابل للتثبيت كتطبيق (PWA) على أي جهاز.

🔗 **الرابط المباشر (GitHub Pages):** https://hypenet2233.github.io/REWAYAT-ALBINA/

---

## ✨ المميزات

- **مركز القيادة الشامل** — نظرة تنفيذية حيّة على كل الأقسام (مؤشرات + تنبيهات + روابط سريعة).
- **لوحة قيادة حيّة** تجمّع المؤشرات والأنشطة فعليًا من بيانات كل الأقسام، وتعرض **الأعمال الميدانية مباشرة** من الموقع.
- **سبعة أقسام إدارية**: المقاولات، مصنع البرتبلات، المخازن، شؤون الموظفين، شؤون العمال، الشؤون المالية، تقنية المعلومات.
- **تبويب جداول المتابعة** — كل مشروع ميداني في بطاقة مستقلة تُدار منفردة (يفتح جدول المشروع المحدّد).
- **تبويب المستندات والنماذج** — بطاقات تفاعلية + نماذج تُسجّل سجلاتها فعليًا في القسم المختصّ.
- **مركز تنبيهات ذكي** — يُظهر التنبيهات الفعلية فقط (مشاريع متوقفة، مخزون منخفض، بلاغات مفتوحة...) مع حذف الكل/الفردي.
- **عمليات كاملة** لكل قسم: إضافة / تعديل / حذف / بحث / فرز / تصدير CSV، مع تبديل العرض بين الجدول والبطاقات.
- **حفظ تلقائي** في المتصفح (localStorage) — يعمل بالكامل دون إنترنت.
- **نموذج المتابعة الميدانية** — نسخة ميدانية لتحديث نسب الإنجاز والملاحظات والطباعة الأفقية (A4)، مع دعم **تعدّد المشاريع**.
- **مزامنة سحابية عبر Supabase** — العامل يرفع تحديثاته والمدير يراها لحظيًا (صفّ لكل مشروع)، بمفتاح anon عام آمن للنشر.
- **قابل للتثبيت (PWA)** — النظام كاملًا أو كل صفحة على حدة، على أي متصفح/جهاز، مع دليل تثبيت مصوّر.

## 📁 بنية المشروع

جميع الملفات في جذر المستودع (بنية مسطّحة تُخدَّم مباشرة عبر GitHub Pages):

```
.
├── index.html                      # الواجهة الرئيسية (الشريط الجانبي + كل التبويبات)
├── admin-core.js                   # محرّك الوحدات الموحّد (يبني كل قسم من إعداداته)
├── seed-data.js                    # مصدر البيانات والمخططات الموحّد (RB_SEED + RB_SCHEMA)
├── sync-config.js                  # إعداد مزامنة Supabase المركزي (رابط + مفتاح anon العام)
│
├── contracting.html                # المقاولات العامة
├── portables.html                  # مصنع البرتبلات
├── warehouses.html                 # المخازن والمستودعات
├── hr.html                         # شؤون الموظفين
├── workers.html                    # شؤون العمال
├── finance.html                    # الشؤون المالية
├── it.html                         # تقنية المعلومات
├── documents.html                  # المستندات والنماذج
├── نموذج المتابعة الميدانية.html    # النموذج الميداني (تعدّد مشاريع + مزامنة Supabase)
├── install.html                    # دليل تثبيت التطبيقات
│
├── sw.js                           # Service Worker (تثبيت + عمل دون اتصال)
├── manifest.webmanifest            # مانفست النظام الرئيسي
├── manifest-field.webmanifest      # مانفست النموذج الميداني
├── m-*.webmanifest                 # مانفست مستقل لكل قسم (تثبيت الصفحة منفردة)
├── icon-192.png · icon-512.png     # أيقونات التطبيق
├── .nojekyll                       # تعطيل معالجة Jekyll (خدمة الملفات كما هي)
└── صور/                            # صور وشعارات مرجعية
```

> ملاحظة: مجلد `مستندات/` (نُسخ احتياطية ومراجع) يبقى محليًا ولا يُنشر علنًا (انظر `.gitignore`).

## 🏗️ المعماريّة

النظام **مبني على إعدادات تعريفية (config-driven)**:
- `admin-core.js` محرّك واحد يبني وحدة إدارية كاملة (مؤشرات + رسوم + جدول/بطاقات + عمليات) من كائن `cfg`.
- `seed-data.js` مصدر موحّد للبيانات (`RB_SEED`) ومخطط الحقول (`RB_SCHEMA`)، تستخدمه الأقسام ولوحة القيادة والنماذج معًا لضمان تطابق البيانات.
- كل قسم = ملف صغير يعرّف `cfg` ويستدعي المحرّك.
- الأقسام تُحمَّل في `index.html` عبر `iframe` (نفس الأصل) وتحفظ بياناتها في `localStorage` بمفتاح لكل قسم (`rb_contracting` … `rb_it`).

## ☁️ المزامنة الميدانية (Supabase)

- إعداد مركزي واحد في `sync-config.js` (`Project URL` + `anon key`) — آمن للنشر (محميّ بصلاحيات RLS على الخادم).
- جدول `field_tracking` (صفّ لكل مشروع): العامل يرفع (upsert) عند الحفظ، والمدير يسحب/يراقب لحظيًا.
- **لا يُوضع أي مفتاح `service_role` أو توكن سرّي في أي ملف منشور.**

## ▶️ التشغيل محليًا

افتح `index.html` بالنقر المزدوج، أو شغّل خادمًا محليًا:

```bash
python -m http.server 8000
# ثم افتح: http://localhost:8000/
```
