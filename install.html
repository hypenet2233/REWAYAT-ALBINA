الخطوات حسب الجهاز

أندرويد — Chrome / Edge / Samsung

  1. افتح التطبيق المطلوب من قائمة «التطبيقات المتاحة» أدناه.
  2. اضغط قائمة المتصفح (⋮) أعلى الشاشة.
  3. اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
  4. أكّد — ستظهر أيقونة التطبيق على شاشتك.

آيفون / آيباد — Safari

  1. افتح التطبيق المطلوب في متصفح Safari.
  2. اضغط زر المشاركة في الأسفل.
  3. مرّر واختر «إضافة إلى الشاشة الرئيسية».
  4. اضغط «إضافة» — يظهر التطبيق على الشاشة.

كمبيوتر — Chrome / Edge

  1. افتح التطبيق المطلوب في المتصفح.
  2. اضغط أيقونة التثبيت في شريط العنوان (يمين).
  3. أو من قائمة (⋮) اختر «تثبيت…».
  4. سيفتح كنافذة تطبيق مستقلة.

فايرفوكس (أندرويد)

  1. افتح التطبيق المطلوب.
  2. اضغط قائمة (⋮).
  3. اختر «إضافة إلى الشاشة الرئيسية».
  4. أكّد الإضافة.

التطبيقات المتاحة للتثبيت

افتح التطبيق (يفتح في نافذة جديدة) ثم اتبع خطوات متصفحك أعلاه لتثبيته.
